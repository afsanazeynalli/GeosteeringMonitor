# GitHub upload guide

1. Create a new repository named `geosteering-statistics-research-pack`.
2. Extract this ZIP and upload its contents at the repository root, or copy them into a local clone and commit.
3. Confirm rights to redistribute `tools/geosteering_statistics_v4.html` before making the repository public. Its source file has no identified license notice; see `LICENSE.md`.
4. Replace the generic author in `CITATION.cff` before publication.
5. Keep proprietary well data out of Git. The supplied CSV is synthetic.

Suggested description: `Standalone geosteering statistics tool with synthetic data and research documentation`

Suggested topics: `geosteering`, `well-logging`, `trajectory-visualization`, `research-software`
